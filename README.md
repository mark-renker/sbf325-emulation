# Stereo Bucket Flanger

An open-source (MIT), non-commercial AU / VST3 / CLAP plugin that models a two-channel analog
bucket-brigade flanger of the late-1970s rack type, inspired by the Roland SBF‑325 Stereo Flanger
(1979–1986): three flanger modes and a chorus mode, per-channel phase inversion, channel‑B modulation
inversion, calibrated feedback that never self-oscillates, NE570-style companding inside the delay
loop, an external CV input, and a bucket-brigade delay simulated at its own variable clock (34 kHz
to 1 MHz) rather than at the host rate. Fidelity is defined by measurement (spec §8), not by
description: every number below comes from `measure/run_all.py`.

The build also produces a standalone renderer (`sbf_render`) that turns WAVs into WAVs and generates
the test stimuli, so the whole measurement suite runs headless and in CI.

## Build

Requirements: CMake ≥ 3.22, a C++17 compiler, JUCE 8.0.6 (a checkout at `~/JUCE` is used when
present, otherwise fetched), Python 3 with numpy / scipy / soundfile / matplotlib for the measurements.

```sh
# plugins (AU/VST3/CLAP/Standalone) + renderer + unit tests
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release        # add -DSBF_ARCHS=arm64 for a native-only dev build
cmake --build build --config Release -j
./build/sbf_tests

# DSP core only (no JUCE), e.g. on a CI box
cmake -S . -B build-core -DSBF_BUILD_PLUGINS=OFF && cmake --build build-core -j

# measurements: re-renders every stimulus, writes docs/results/{results.json,RESULTS.md,plots/},
# exits non-zero if any Section 8 threshold regresses
python3 measure/run_all.py build/sbf_render --out docs/results [--reference captures/]
# or: make -C measure verify
```

Built bundles land in `build/StereoBucketFlanger_artefacts/Release/{AU,VST3,CLAP,Standalone}`; copy them
into `~/Library/Audio/Plug-Ins/{Components,VST3,CLAP}` (ad-hoc sign with `codesign --force --deep -s -`
if needed).

### Renderer

```sh
sbf_render --mode fl2 --manual 2 --rate 0.5 --depth 60 --feedback 75 in.wav out.wav
sbf_render --gen sweep:20:20000 --len 4 --amp -12 --mode fl3 --chb-mod inv out.wav
sbf_render --info --manual 0.5          # latency, clock range, expected delay, tunables (JSON)
sbf_render --cpu                        # per-instance CPU at 48 kHz / 64-sample buffers
sbf_render --set compTauMs=100 ...      # override any model constant (src/dsp/Tunables.h)
```

## Parameters (all in real units)

| Parameter | Range | Hardware control |
|---|---|---|
| Mode | Off / Flanger I / Flanger II / Flanger III / Chorus | EFFECT MODE |
| Manual | 0.5–15 ms (Chorus 5–15 ms) | MANUAL |
| Rate | 0.02–5 Hz, log | RATE |
| Depth | 0–100 % | DEPTH |
| Feedback | 0–100 % of the calibrated maximum (never oscillates) | FEEDBACK LEVEL |
| CH‑B Mod | Normal / Invert | CH‑B MOD |
| CH‑A / CH‑B Phase | Normal / Invert | PHASE switches |
| Ext CV | Off / Sidechain (bus 2, ±1) / Parameter (±1) — replaces the LFO | EXT CV IN |
| Input / Output Level | 0 / −20 dB plus ±6 dB fine | INPUT / OUTPUT LEVEL |
| Noise | model the BBD noise floor and clock feedthrough (default on) | — |
| Rate Sync | Off (default) or note values against host tempo | — |
| Bypass | hard bypass, unity (delayed by the reported latency) | BYPASS |

Latency reported to the host: 4 samples (the 2× half-band round trip used by the delay-line island);
algorithmic latency is zero.

## Repository layout

| Path | Content |
|---|---|
| `src/dsp/` | JUCE-free DSP core: `Bbd.h` (variable-clock bucket brigade), `ModalFilter.h` (analog filters advanced exactly between clock ticks), `Compander.h` (NE570), `Lfo.h`, `Flanger.h` (modes, matrix, control path), `Tunables.h` |
| `src/plugin/` | JUCE processor and editor |
| `tools/Render.cpp` | standalone renderer / stimulus generator |
| `tests/UnitTests.cpp` | per-block unit tests |
| `measure/` | Python measurement scripts, `run_all.py`, `Makefile` |
| `docs/` | spec PDF, `BLOCK_DIAGRAM.md`, `MEASUREMENT_PROTOCOL.md`, `ASSUMPTIONS.md`, `results/` |
