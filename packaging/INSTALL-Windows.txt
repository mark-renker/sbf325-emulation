Stereo Bucket Flanger - Windows install

1. Copy the "Stereo Bucket Flanger.vst3" folder to   C:\Program Files\Common Files\VST3\
2. Copy "Stereo Bucket Flanger.clap" to              C:\Program Files\Common Files\CLAP\   (Bitwig, Reaper, other CLAP hosts)
3. Rescan plug-ins in your DAW. The plug-in appears under "Renky Denk".
4. "Stereo Bucket Flanger.exe" is the standalone app; it runs from anywhere. If SmartScreen warns about an
   unrecognized app, click More info > Run anyway (the build is not code-signed).

To retune the model after measuring hardware, create %APPDATA%\StereoBucketFlanger\tunables.txt (one key=value
per line, keys from src/dsp/Tunables.h); it is read each time the plug-in is loaded. sbf_render.exe is the
command-line WAV renderer used by the measurement scripts.
